# Gravity Paint
A platformer game where you must paint the walls of a cave to make your way out of the mysterious alien planet. Use your gravity gun to paint different colors to change gravity.

## How to Play
* **W, A, S, D** - Move
* **Left Click** - Shoot/Select
* **Mouse** - Aim
* **R** - Restart
* **Esc** - Level Selection

## Built With
* **Language:** JavaScript
* **Editor:** VS Code
